## ✨ Key Features

- **🎨 Modern Dark Aesthetic:** Sleek deep navy and charcoal palette with vibrant electric blue (`#7bd0ff`) and royal blue (`#2563eb`) accents.
- **📱 Fully Responsive & Adaptive:** Mobile-first architecture featuring a smooth slide-out navigation drawer.
- **⚡ Scrollspy Navigation:** Sticky glassmorphic navbar with active section detection as you scroll.
- **📨 Direct Gmail Form Delivery:** Fully connected via FormSubmit API with automatic delivery to Gmail, loading animations, confirmation alerts, and instant Gmail compose fallback.
- **📋 One-Click Email Copy:** Clipboard copy action with animated floating toast notifications.
- **🔍 SEO & Semantic Architecture:** Structured heading hierarchy, metadata, OpenGraph readiness, and accessible markup.
